# Description
The following project is based on creating custom functions inspired by existing ones, as well as others that provide utility for future projects.

For the creation of these functions, the use of external libraries is not allowed; furthermore, the rules established by 42 Madrid must be followed. The project includes a Makefile which allows us to create the library libft.a, remove the dependent files used for its creation, and delete the library itself.

# Instructions

The goal is to create a library called libft.a, which will contain the following functions mentioned below:
+ libc functions
+ Additional functions
+ Linked lists
+ Makefile


### Creating the static library
The creation of the library will be done using the Makefile tool. You must execute the following command in the console:

> make

### Removing *.o files
To remove the *.o files, execute the following command:
> make clean

### Removing files and the library
To remove the library and all *.o files, execute the following command:
> make fclean
